# 🩸 متابع السكر الذكي (Smart CGM)

تطبيق أندرويد بيقرا حساسات السكر **LinX / AiDEX X** و **FreeStyle Libre 2/3** و **Sibionics GS1**،
ويدّي تنبيهات ذكية، وجدول ساعي، وتقارير للدكتور، ومتابعة للأهل.

> ⚕️ التطبيق أداة مساعدة، مش جهاز طبي معتمد. أي جرعة مقترحة لازم تتراجع.

## 🧱 التصميم في سطر
الحساس ← **Juggluco** (بيفك تشفير البلوتوث) ← تطبيقنا (الذكاء + التنبيهات + الجدول + المشاركة).

ليه؟ تشفير بلوتوث الحساسات دي سري ومعقد، و Juggluco مشروع مفتوح ومجرَّب بيفكه لكل الأنواع الأربعة.
لو مش عايز Juggluco: التطبيق بيقرا القراءة من إشعار تطبيق LinX الرسمي كبديل.

## 📂 الملفات
| المكان | إيه اللي فيه |
|---|---|
| `core/` | كل الحسابات الطبية (معايرة، اتجاه، توقع الهبوط، الأنسولين الفعال، الجرعة، الإحصائيات، عمر الحساس، التنبيهات، الجدول) + اختبارات |
| `app/` | تطبيق الأندرويد (الشاشات، الخدمة الخلفية، الكاميرا، التصدير، المشاركة) |
| `docs/RESEARCH.md` | خلاصة البحث |
| `backend/` | سيرفر المشاركة على Cloudflare Workers + D1 (مجاني) |

## ⬇️ تنزيل الـAPK
**لينك مباشر (Cloudflare):** https://smartcgm-download.mflma2040.workers.dev/SmartCGM.apk

افتحه من الموبايل وهينزل الملف على طول. النسخة الحالية مبنية من `main` (commit `bd98acd`)،
SHA-256: `47f495ccfb05dba95c2dd61bd48af8225ee3d927c7513ee912de585989067fb8` (الهيدر `X-SHA256` بيرجع نفس القيمة).

كل رفع على GitHub بيبني APK أوتوماتيك كمان: **Actions ← Build APK ← SmartCGM-apk**.
اللينك ده لسه مش بيتحدّث لوحده مع كل بناء؛ ده محتاج secret اسمه `CLOUDFLARE_API_TOKEN` في الريبو (مش موجود حاليًا).
